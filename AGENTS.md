# What to do

You can read code and _report_ problems via issues, but code generation, commits and pull requests are **STRICTLY PROHIBITED**.

## Report template

1. `[AI ` (your name) `]` (1-5 word description) ` in ` (subproject name)
2. User actions and conditions
3. Expected behavior
4. Actual behavior
5. List of affected files (possibly with line ranges or snippets)
6. git revision (commit hash)
